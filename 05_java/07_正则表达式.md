# 正则表示

正则表达式是一种pattern，用于描述文本的格式



[] 表示一个字符，里面必须有内容

[0-9]  数字

[a-z] 小写字母

[A-Z] 大写字母

[0-5a-zA-Z] 0-5和字母

[^0-9] 非数字



\d 一个数字，相当于[0-9]，**注意，java中，需要使用\\\\表示**

\D 一个非数字，相当于\[^0-9]

\w 一个常用字符，相当于[a-zA-Z]

\W \w的取反，即不是一个常用字符

\ 转义字符 [0-9\\-]中 \\- 解析为减号 **注意是减号，不是减法！**

\s 一个空白字符

. 任何一个字符



() 表示整体，如(az)表示"az"是个整体

| 表示或，(az | xyz)表示"az"或者"xyz"



{n} 前方内容出现n次，如[0-9]{3}表示出现3次数字

{n,m} 前方内容出现n到m次，如[0-9]{2,6}表示2~6个数字

{n,} 前方内容至少出现n次，如[0-9]{2,}表示数字出现至少2次

正则表达式没有“至多n次”的语法，可以使用{0,n}表示至多n次



\* 表示任意次，相当于{0,}

\+ 表示至少出现1次，相当于{1,}

？表示至多出现一次，相当于{0,1}

^ 表示一行的开始

$ 表示一行的结束



例：

1. 判断某个字符串 是否符合 某个正则表达式

```java
/**
 * 1. @符号前可以是小写字母，数字，下划线，减号和句点
 * 2. 前两位必须是小写字母
 * 3. @与后面句点之间的内容是neusoft
 * 4. 最后的句点结尾后面是com或net
 */
// 符合这个需求的正则表达式
String regex = "^[a-z]{2}[a-z0-9_\\-\\.]*@neusoft\\.(com|net)$";
String oriStr = "aahaha01@neusoft.com";
oriStr.matches(regex); // 返回值为boolean
```

2. 从一个字符串中，通过正则表示，取出符合条件的子串

```java
import java.util.regex.Matcher;
import java.util.regex.Pattern;

String str = "Az哈哈@12#3561alal9820ZZZ@#113331Wa嘻嘻x";
String regex = "[0-9]+";

Pattern p = Pattern.compile(regex); //编译要寻找内容的正则
Matcher m = p.matcher(str);  //用正则去匹配目标字符串

while(m.find()) // 在目标里寻找
{
    String s = m.group();
    int num = Integer.parseInt(s); //String -> int
    System.out.println(num);
}
```
