# 顺序

项目的编写顺序

1. common / ResponseResult：包含返回成功结果，返回错误结果
2. common / GlobalExceptionHandler：全局拦截处理异常
3. interceptor / TokenInterceptor：实现tokne校验
4. WebmvcConfig：实现WebMvcConfiguration接口，配置拦截器
5. dto / LoginDTO：登录时，前端向后端发送的信息
6. handler / SystemHandler：controller
7. service / SystemService：接口
8. service / impl / SystemServiceImpl
9. 重回 handler / SystemHandler：补完这个controller
10. mapper / SystemMapper：mapper
11. 重回 service / impl / SystemServiceImpl：补完service实现
