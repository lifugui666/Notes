# 事务控制

## 场景：

现有2张表，用户表、学历表，分别记录用户的基本信息和学历信息

显然，有些用户会有2条甚至3条学历信息（本科、硕士、博士）

此时，如果需要新增用户，那么除了在用户表中新增基本信息，还需要在学历表中新增学历信息，很明显，新增用户将涉及到两张表的操作，是一个**事务**，需要保证操作的原子性

在之前使用JDBC写代码时，我们会通过同一个connection和rollback实现原子性



## 使用框架实现事务控制



### 参数校验

前端传参会包含两部分信息，分别是：

1. 用户基本信息
2. 用户学历信息

参数Json如下所示

```json
{
    "uname":"kfc",
    "account":"kfc123"
    "password":123,
    "edulist":[
    	{
    		"collage":"A大学",
    		"major":"a专业",
    		"inyear":1997,
    		"outyear":1998
		},
		{
            "collage":"A大学",
    		"major":"a专业",
    		"inyear":2000,
    		"outyear":2001
        }
    ]
}
```

需要用两个类接收这两种参数并进行合法性校验

```java
@Data
public class UserDTO {
	@NotBlank(message = "用户名字不能为空")
	private String uname;
	@NotBlank(message = "账号不能为空")
	private String account;
	@NotBlank(message = "密码不能为空")
	private String password;
	@Valid //Valid注解表示要去EducationDTO中进行递归式的合法性检查
	private List<EducationDTO> edulist;
}
```

```java
@Data
public class EducationDTO {
	@NotBlank(message = "学校不能为空")
	private String college;
	@NotBlank(message = "专业不能为空")
	private String major;
	@NotNull(message = "入学年份不能为空")
	private Integer inyear;
	private Integer outyear;
}
```



### controller层（无改动

### Service层（事务控制的重点

要点：

* 使用`@Transactional`注解实现错误时回滚

```java
@Service
@RequiredArgsConstructor
public class UserServiceImpl implements UserService {

	private final UserMapper mapper;

	@Override
	@Transactional(rollbackFor = Exception.class)   //事务控制：不加rollbackFor 在发生RuntimeException和Error才会回滚
	public Integer addNewUser(UserDTO dto) {
		//1. 在users表中新增user的基本数据，返回本次新增的userid -> po类的userid
		UserPO upo = new UserPO();
		upo.setUname(dto.getUname());
		upo.setAccount(dto.getAccount());
		upo.setPassword(dto.getPassword());
		mapper.insertUser(upo);

		//2. 在educations表中新增user的教育信息
		if(dto.getEdulist() != null){
			for(EducationDTO d : dto.getEdulist()){
				EducationPO epo = new EducationPO();
				epo.setUserid(upo.getUserid());
				epo.setCollege(d.getCollege());
				epo.setMajor(d.getMajor());
				epo.setInyear(d.getInyear());
				epo.setOutyear(d.getOutyear());
				mapper.insertEducation(epo);
			}
		}

		return 0;
	}
}
```
