# 延时列表

真正的FreeRTOS工作时，如果一个任务需要进入延时状态，那么这个任务就要被移出就绪列表

那么，移出就绪列表的任务总是需要一个去处的，这个去处就是延时列表



## 延时列表的工作原理

当任务进入延时列表之后，会更新xNextTaskUnblockTime值，这个值表示的是下一个结束延时的任务的 延时结束时刻；

这个值 = 系统时基计数器 + 需要延时的值

当 系统时基计数器 的值 == xNextTaskUnblockTime时，就代表有任务结束了延时，需要被重新添加回准备就绪序列；

### 初始化延时链表

void prvInitialiseTaskLists( void )

    pxOverflowDelayedTaskList = &xDelayedTaskList2;

### 将任务插入延时列表的功能

```c
void vTaskDelay( const TickType_t xTicksToDelay )
{
    TCB_t *pxTCB = NULL;
    /* 获取当前任务的TCB */
    pxTCB = pxCurrentTCB;
    /* 不在使用直接设置xTicksToDelay 来设置延时时间 */
    //pxTCB->xTicksToDelay = xTicksToDelay;(1)
    /* 将任务插入到延时列表 */
    prvAddCurrentTaskToDelayedList( xTicksToDelay );(2)
    /* 任务切换 */
    taskYIELD();
}
```

注意：为什么要设计两个链表来存放进入延时状态的任务？

因为现在我们是通过xTickCount（时基）判断一个任务是否该被唤醒的，时基本身只是一个变量，是存在溢出可能性的，如果不考虑移除，会出现以下状况：

时基 = 0xFFFF FFF9，延时时长为F；很明显，此时时基+时长超出了0XFFFF FFFF，发生溢出，唤醒时间将是 0x0000 0009；那么当时基再次更新，更新到0xFFFF FFFFA，尽管之过去了一个SysTick，但是程序会认为0x0000 0009这个任务早就该被唤醒；这就会导致任务被错误的唤醒；

因此设计了两个延时任务列表，一旦出现溢出情况，就把任务放在另一个链表里，当时基溢出时，切换两条链表，保证任务不会被错误唤醒；

```c
static void prvAddCurrentTaskToDelayedList( TickType_t xTicksToWait )
{
    TickType_t xTimeToWake;

    /* 获取系统时基计数器xTickCount的值 */
    const TickType_t xConstTickCount = xTickCount;(1)

    /* 将任务从就绪列表中移除 */(2)
    if ( uxListRemove( &( pxCurrentTCB->xStateListItem ) )
            == ( UBaseType_t ) 0 )
    {
        /* 将任务在优先级位图中对应的位清除 */
        portRESET_READY_PRIORITY( pxCurrentTCB->uxPriority,
                                uxTopReadyPriority );
    }

    /* 计算任务延时到期时，系统时基计数器xTickCount的值是多少 */(3)
    xTimeToWake = xConstTickCount + xTicksToWait;

    /* 将延时到期的值设置为节点的排序值 */(4)
    listSET_LIST_ITEM_VALUE( &( pxCurrentTCB->xStateListItem ),
                            xTimeToWake );

    /* 溢出 */(5)
    if ( xTimeToWake < xConstTickCount )
    {
        vListInsert( pxOverflowDelayedTaskList,
                &( pxCurrentTCB->xStateListItem ) );
    }
    else/* 没有溢出 */
    {
        vListInsert( pxDelayedTaskList,
        &( pxCurrentTCB->xStateListItem ) );(6)

        /* 更新下一个任务解锁时刻变量xNextTaskUnblockTime的值*/(7)
        if ( xTimeToWake < xNextTaskUnblockTime )
        {
            xNextTaskUnblockTime = xTimeToWake;
        }
    }
}
```



### 修改 系统时基更新函数 xTaskIncrementTick

回想一下，最初的 xTaskIncrementTick 函数：扫描整个就绪列表，把延时的变量!=0的任务 的 延时变量--，如果延时变量归零，则说明延时结束；

重写一下这个函数

```c
void xTaskIncrementTick( void )
{
    TCB_t * pxTCB;
    TickType_t xItemValue;

    const TickType_t xConstTickCount = xTickCount + 1;// 时基+1
    xTickCount = xConstTickCount; // 更新时基

    /* 如果xConstTickCount溢出，则切换延时列表 */(2)
    if( xConstTickCount == ( TickType_t ) 0U )
    {
        taskSWITCH_DELAYED_LISTS();
    }

    /* 最近的延时任务延时到期 */
    // xNextTaskUnblockTime是最近一个延时任务结束的时间
    if( xConstTickCount >= xNextTaskUnblockTime )
    {
        for( ;; )
        {
            if( listLIST_IS_EMPTY( pxDelayedTaskList ) != pdFALSE )(4)
            {
                /* 延时列表为空，设置xNextTaskUnblockTime为可能的最大值 */
                xNextTaskUnblockTime = portMAX_DELAY;
                break;
            }
            else /* 延时列表不为空 */(5)
            {
                pxTCB = ( TCB_t * ) listGET_OWNER_OF_HEAD_ENTRY( pxDelayedTaskList );
                xItemValue = listGET_LIST_ITEM_VALUE( &( pxTCB->xStateListItem ) );(6)

                /* 直到将延时列表中所有延时到期的任务移除才跳出for循环 */(7)
                if( xConstTickCount < xItemValue )
                {
                    xNextTaskUnblockTime = xItemValue;
                    break;
                }

                /* 将任务从延时列表移除，消除等待状态 */(8)
                ( void ) uxListRemove( &( pxTCB->xStateListItem ) );

                /* 将解除等待的任务添加到就绪列表 */
                prvAddTaskToReadyList( pxTCB );(9)
            }
        }
    }/* xConstTickCount >= xNextTaskUnblockTime */

    /* 任务切换 */
    portYIELD();(10)
}
```



### 切换延时列表的函数

```c
#define taskSWITCH_DELAYED_LISTS()
{
    List_t *pxTemp;(1)
    pxTemp = pxDelayedTaskList;
    pxDelayedTaskList = pxOverflowDelayedTaskList;
    pxOverflowDelayedTaskList = pxTemp;
    xNumOfOverflows++;
    prvResetNextTaskUnblockTime();(2)
}
```

切换延时列表之后，还需要刷新一下xNextTaskUnblockTime

```c
static void prvResetNextTaskUnblockTime( void )
{
    TCB_t *pxTCB;

    if ( listLIST_IS_EMPTY( pxDelayedTaskList ) != pdFALSE )
    {
        /* 当前延时列表为空，则设置xNextTaskUnblockTime等于最大值 */
        xNextTaskUnblockTime = portMAX_DELAY;
    }
    else
    {
        /* 当前列表不为空，则有任务在延时，则获取当前列表下第一个节点的排序值
        然后将该节点的排序值更新到xNextTaskUnblockTime */
        ( pxTCB ) = ( TCB_t * ) listGET_OWNER_OF_HEAD_ENTRY( pxDelayedTaskList );
        xNextTaskUnblockTime = listGET_LIST_ITEM_VALUE( &( ( pxTCB )->xStateListItem ) );
    }
}
```
