# 多优先级支持



之前的例子里，进行任务调度的时候并没有考虑任务优先级

接下来要让调度器支持优先级

这章不考虑延时列表的存在，所有任务都被放在就绪列表里，哪怕任务进入延时状态，也不把这个任务从就绪列表里移除



## 就绪列表

pxReadyTasksLists[ configMAX_PRIORITIES ] 就绪列表

就绪列表本身是一个链表数组，该数组最多可以存放256个链表，对应256个优先级

在FreeRTOS中，优先级数字越小，优先级越低，0是优先级最低的级别，一般就是空闲任务了

任务在创建的时候，需要将任务插入就绪列表中对应的优先级链表里，比如优先级为1的任务就插入到pxReadyTasksLists[1]中即可

（除去就绪列表外，还有挂起列表、延时列表、等待列表等，总是如果你确定一个任务需要被尽快执行，放到就绪列表里，如果一个任务需要被挂起，那么就需要把这个任务的TCB从就绪列表 -> 挂起列表）

## 任务调度

任务调度就是查询就绪列表里优先级最高的就绪任务，然后切换；

任务调度会用到一系列宏定义

```c
/* 查找最高优先级的就绪任务：通用方法 */
#if ( configUSE_PORT_OPTIMISED_TASK_SELECTION == 0 )(1)

/*----------------------------------------------------------*/
/* uxTopReadyPriority 存的是就绪任务的最高优先级 */
/* 查询一个优先级是否比当前记录的最高优先级还要高 */
/* 如果更高，则更新当前记录的最高优先级 */
#define taskRECORD_READY_PRIORITY( uxPriority )\
    {\
        if( ( uxPriority ) > uxTopReadyPriority )\
        {\
            uxTopReadyPriority = ( uxPriority );\
        }\
    }

/*-----------------------------------------------------------*/
/* 遍历任务就绪列表 寻找当前优先级最高的任务 */
/* 这个任务给当前TCB指针 然后更新当前最高优先级 */
#define taskSELECT_HIGHEST_PRIORITY_TASK()\(3)
    {\
        UBaseType_t uxTopPriority = uxTopReadyPriority;\
        /* 寻找包含就绪任务的最高优先级的队列 */\
        while( listLIST_IS_EMPTY( &( pxReadyTasksLists[ uxTopPriority ] ) ) )\
        {\
            --uxTopPriority;\
        }\
        /* 获取优先级最高的就绪任务的TCB，然后更新到pxCurrentTCB */\
        listGET_OWNER_OF_NEXT_ENTRY(pxCurrentTCB, &(pxReadyTasksLists[ uxTopPriority ]));\
        /* 更新uxTopReadyPriority */\
        uxTopReadyPriority = uxTopPriority;\(3)-4
    }

/*-----------------------------------------------------------*/
/* 这两个宏定义只有在选择优化方法时才用，这里定义为空 */
#define taskRESET_READY_PRIORITY( uxPriority )
#define portRESET_READY_PRIORITY( uxPriority, uxTopReadyPriority )


//-------以上是通用方法-------------------
//---------------------------------------
//-------以下是优化方法-------------------


/* 查找最高优先级的就绪任务：根据处理器架构优化后的方法 */
#else/* configUSE_PORT_OPTIMISED_TASK_SELECTION */(4)

#define taskRECORD_READY_PRIORITY( uxPriority ) \(5)
    portRECORD_READY_PRIORITY( uxPriority, uxTopReadyPriority )

/*-----------------------------------------------------------*/
/* 先寻找当前最高优先级 然后再将最高优先级的任务给 pxCurrentTCB */
#define taskSELECT_HIGHEST_PRIORITY_TASK()\(7)
    {\
        UBaseType_t uxTopPriority;\
        /* 寻找最高优先级 */\
        portGET_HIGHEST_PRIORITY( uxTopPriority, uxTopReadyPriority );\
        /* 获取优先级最高的就绪任务的TCB，然后更新到pxCurrentTCB */\
        listGET_OWNER_OF_NEXT_ENTRY( pxCurrentTCB, &( pxReadyTasksLists[ uxTopPriority ] ) );\
    }/* taskSELECT_HIGHEST_PRIORITY_TASK() */

/*-----------------------------------------------------------*/
/* 重置当前优先级状态 */
/* 如果uxPriority表示的优先级链表里已经没有任务，则将对应的位 置位为0 */
#define taskRESET_READY_PRIORITY( uxPriority )\
    {\
        if(listCURRENT_LIST_LENGTH(&(pxReadyTasksLists[( uxPriority)]))==(UBaseType_t)0)\
        {\
            portRESET_READY_PRIORITY( ( uxPriority ), ( uxTopReadyPriority ) );\
        }\
    }

#endif/* configUSE_PORT_OPTIMISED_TASK_SELECTION */
```



### 通用的调度方法

**taskSELECT_HIGHEST_PRIORITY_TASK()**

```c
#define taskSELECT_HIGHEST_PRIORITY_TASK()\(3)
    {\
        /* uxTopReadyPriority的值存放在 uxTopPriority 中 备用*/
        UBaseType_t uxTopPriority = uxTopReadyPriority;\
        /* 寻找包含就绪任务的最高优先级的队列 */\
        while( listLIST_IS_EMPTY( &( pxReadyTasksLists[ uxTopPriority ] ) ) )\
        {\
            /* 如果没有找到，就uxTopPriority-- */
            /* 因为空闲任务的存在，所以这个循环是一定会退出的... */
            --uxTopPriority;\
        }\
        /* 获取优先级最高的就绪任务的TCB，然后更新到pxCurrentTCB */\
        listGET_OWNER_OF_NEXT_ENTRY(pxCurrentTCB, &(pxReadyTasksLists[ uxTopPriority ]));\
        /* 更新uxTopReadyPriority */\
        uxTopReadyPriority = uxTopPriority;\(3)-4
    }/* taskSELECT_HIGHEST_PRIORITY_TASK */
```

通用方法就是通过遍历就绪队列，找到优先级最高的任务，然后更新当前最高优先级

此时的taskRECORD_READY_PRIORITY

### 优化的调度方法

使用这个优化的调度方法，有两个前提条件：

1. configUSE_PORT_OPTIMISED_TASK_SELECTION = 1
2. 优先级配置不能超过32（FreeRTOS是支持256级优先级配置的，但是要用优化的调度方法，就不能配置优先级级数超过32）

优化方法能够实现，依赖于Cortex-M的指令  CLZ

CLZ指令能够计算一个二进制值，最前面有几个0

比如  0b0000 1111 使用CLZ，就能得到4；0b 0000 0111 使用CLZ就能得到5；

使用CLZ结合uxTopReadyPriorit，可以计算出当前优先级最高的任务；

当前最高优先级 = ( 31UL - (uint32_t )__clz( ( uxReadyPriorities ) ) ) 

其中31UL表示：unsigned Long 类型，数值为31

(uint32)进行强制类型转换，防止类型出错

__clz( ( uxReadyPriorities ) ) 计算uxReadyPriorities 的先导0数量

```c
#define taskSELECT_HIGHEST_PRIORITY_TASK()\(7)
    {\
        UBaseType_t uxTopPriority;\
        /* 寻找最高优先级 */\
        portGET_HIGHEST_PRIORITY( uxTopPriority, uxTopReadyPriority );\
        /* 获取优先级最高的就绪任务的TCB，然后更新到pxCurrentTCB */\
        listGET_OWNER_OF_NEXT_ENTRY( pxCurrentTCB, &( pxReadyTasksLists[ uxTopPriority ] ) );\
    }/* taskSELECT_HIGHEST_PRIORITY_TASK() */
```



## 修改代码以支持多优先级

### 修改TCB

在TCB中增加一个成员，表明这个任务的优先级是多少



### 修改xTaskCreateStatic

prvInitialiseNewTask函数，新增一个参数，用于初始化TCB里的优先级

新增调用一个函数，prvAddNewTaskToReadyList( pxNewTCB );将pxNewTCB 添加到就绪列表中



### 修改prvInitialiseNewTask

新增参数，用于表明TCB的优先级

新增功能，用于将参数传入的优先级，放入TCB中



### 新增prvAddNewTaskToReadyList函数

改函数负责将一个任务添加到就绪列表中

```c
static void prvAddNewTaskToReadyList( TCB_t *pxNewTCB )
{
    /* 进入临界段 */
    taskENTER_CRITICAL();
    {
        /* 全局任务计时器加一操作 */
        uxCurrentNumberOfTasks++;(1)
        /* 如果pxCurrentTCB为空，则将pxCurrentTCB指向新创建的任务 */
        if ( pxCurrentTCB == NULL )(2)
        {
            pxCurrentTCB = pxNewTCB;
            /* 如果是第一次创建任务，则需要初始化任务相关的列表 */
            if ( uxCurrentNumberOfTasks == ( UBaseType_t ) 1 )(3)
            {
                /* 初始化任务相关的列表 */
                prvInitialiseTaskLists();
            }
        }
        else/* 如果pxCurrentTCB不为空，(4)
        则根据任务的优先级将pxCurrentTCB指向最高优先级任务的TCB */
        {
            if ( pxCurrentTCB->uxPriority <= pxNewTCB->uxPriority )
            {
                pxCurrentTCB = pxNewTCB;
            }
        }
        /* 将任务添加到就绪列表 */
        prvAddTaskToReadyList( pxNewTCB );(5)
    }
    /* 退出临界段 */
    taskEXIT_CRITICAL();
}
```



### 修改vTaskSwitchContext函数

现在让程序自己去找优先级最高的任务即可，不需要再手动进行切换了

```c
void vTaskSwitchContext( void )
{
/* 获取优先级最高的就绪任务的TCB，然后更新到pxCurrentTCB */
    taskSELECT_HIGHEST_PRIORITY_TASK();
}
```



### 修改 vTaskDelay

注意：FreeRTOS在处理进入延时的任务时，会把该任务从就绪列表里移到延时列表里；但是鉴于笔记写到这里，还没接触到延时列表，所以这里暂时先通过修改任务优先级别的方式，让调度器在进行调度时忽略这个任务；

```c
void vTaskDelay( const TickType_t xTicksToDelay )
{
    TCB_t *pxTCB = NULL;

    /* 获取当前任务的TCB */
    pxTCB = pxCurrentTCB;

    /* 设置延时时间 */
    pxTCB->xTicksToDelay = xTicksToDelay;

    // 更新当前最高优先级
    taskRESET_READY_PRIORITY( pxTCB->uxPriority );

    /* 任务切换 */
    taskYIELD();
}
```
