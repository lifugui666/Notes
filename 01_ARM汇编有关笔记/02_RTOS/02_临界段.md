# 临界段



临界段指的是可能被共享的访问资源，全局变量、寄存器、队列等都属于临界段

临界段保护主要是为了消除竞争造成的不确定状态

## 关中断

如果在程序操作全局变量的时候直接把中断关了，那肯定可以保证临界段的安全；

```assembly
CPSID I ;PRIMASK=1     ;关中断
CPSIE I ;PRIMASK=0     ;开中断
CPSID F ;FAULTMASK=1   ;关异常
CPSIE F ;FAULTMASK=0   ;开异常
```

不过这有些太极端了，没有给其他中断留一点点余地，失去了灵活度



## 使用BASEPRI

这个寄存器给了用户屏蔽中断的功能，可以通过设置该寄存器的值，决定屏蔽低级中断

FreeRTOS提供了两个基于basepri的关中断方法

```c
/* 不带返回值的关中断函数，不能嵌套，不能在中断里面使用 */(1)
#define portDISABLE_INTERRUPTS() vPortRaiseBASEPRI()

void vPortRaiseBASEPRI( void )
{
    uint32_t ulNewBASEPRI = configMAX_SYSCALL_INTERRUPT_PRIORITY;
    __asm
    {
        msr basepri, ulNewBASEPRI
        dsb
        isb
    }
}

/* 带返回值的关中断函数，可以嵌套，可以在中断里面使用 */(2)
#define portSET_INTERRUPT_MASK_FROM_ISR() ulPortRaiseBASEPRI()
ulPortRaiseBASEPRI( void )
{
    uint32_t ulReturn, ulNewBASEPRI = configMAX_SYSCALL_INTERRUPT_PRIORITY;
    __asm
    {
        mrs ulReturn, basepri
        msr basepri, ulNewBASEPRI
        dsb
        isb
    }
    return ulReturn;
}
```

第一个关中断方法没有返回值，不能进行嵌套，也不能在中断内使用：

中断屏蔽等级5 -> 接触中断屏蔽  可以

中断屏蔽等级5 -> 中段屏蔽等级3 -> 接触中断屏蔽等级3 -> 解除中断屏蔽等级5 不行

而第二个由于返回值返回了当前的中断屏蔽等级，可以将当前中断屏蔽等级记录下来，不会导致无法恢复，因此可以嵌套



进入临界段之前，要记得进行临界段保护即可
