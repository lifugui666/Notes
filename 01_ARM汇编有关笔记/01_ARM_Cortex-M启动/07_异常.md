# 异常



## 异常如何引发？

最经典的除零就可以引发除以0异常

```assembly
# ......
    mov r0, #0x01
    mov r1, #0x00
    udiv r0, r0, r1 # 这就触发了除0异常
    mov r0, #0x01   # return address不是这行
# ......

HardFault_Hanlder:
    bx lr
```

异常的处理和中断的处理基本一样，不过压栈的return address不是udiv下一行的地址，而是 udiv r0, r0, r1这行本身的地址

所以HardFault_Hanlder在bx lr之后，又会回到udiv这行，然后来来回回不断跳转到HardFault_Hanlder再跳转到udiv

如果需要让程序继续执行下去，需要在HardFault_Hanlder中通过查栈的方式，找到return address并修改，让程序能够继续执行下去
